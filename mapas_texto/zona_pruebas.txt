; ZONA DE PRUEBAS: mapa para probar sprites, enemigos y movimiento. No es parte de
; la ruta ni del juego: no tiene salidas y ninguna escena lleva aquí. El Player es
; prisn.tscn, igual que al empezar la partida: sale sin espada; con la espada se
; prueba desde el Modo dev (tecla º, "Dar espada"). Para volver a sin espada,
; reiniciar la escena con F6.
;
; De izquierda a derecha, cada tramo se cruza también sin espada:
;   x 2-22    inicio: pasillo plano, checkpoint, cofre, poción y armadura
;   x 24-32   colina con rampas
;   x 36-38   foso de pinchos (matan) y fuego en x 42 (quema)
;   x 45-63   plataformas de una vía hacia la galería alta
;   x 69      escalera que atraviesa el piso, filas 11-19, con checkpoint en x 64
;   x 83      escalera de la galería a la cornisa (cofre en x 88); kolbo en la galería
;   x 73-143  corrales de enemigos, abajo, separados por columnas: rata, slime,
;             esqueleto, esqueleto de lanza, Guardia, Aprendis, y mino con diablillo
;
; Los enemigos sin letra y lo que se ponga a mano para probar van en
; zona_pruebas_combate.tscn, que hereda de esta escena: regenerarla no los borra.
; Probar el mapa desde esa. Detalle en docs/P43_ZONA_DE_PRUEBAS.md.
; Generar desde la carpeta del proyecto:
;   ~/.local/bin/godot --headless res://herramientas/constructor_mapas/construir_mapa.tscn -- mapas_texto/zona_pruebas.txt
